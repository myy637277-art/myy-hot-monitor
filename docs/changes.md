# 2026-10-30 改动说明

这一版让监控到点自己采集再发日报，并把来源开关、可信名单和首页变化标到页面上。邮件仍不发。

## 采集和日报

打开「每天推送」后，到了设定的北京时间先采集。这一轮结束再发日报。当时已经有一轮在跑，就等它结束，不另开一轮。采集失败仍用库里已有的故事发。进程没开着，错过的那一次不补。同一天定时发送成功后不再发第二次。

「日报」页列出最近 30 次发送：时间、定时或手动、状态、条数。不存正文。推送时间和范围仍在设置页。

默认的 X「AI」查询仍只拉近 24 小时。

## 来源开关

设置页每个来源可以关。关掉的这一轮不请求。默认全开。状态显示「已关闭」。

## 可信来源

设置页可以添加域名或 X 账号。第一次使用时写入现有 17 个官方账号，以及公式里的 11 个官方域名。删掉的不会在重启时补回。

名单里的来源提高可信度，精确匹配的账号和域名不会被仿冒规则误伤。没点名的 X 仍要至少 10 万粉丝、浏览量至少 1000 才入库，可信度低于名单内。仿冒、黑名单、诈骗用语仍把最终可信度封顶在 30。

用户添加的域名也可以作为首页收录的权威站点。

## 首页变化

一次采集之后，新上首页的故事标「新上榜」。来源数比上次变多，标「多了 N 个来源」。没有变化不标。升级后的第一次采集只记下当前来源数，不把已有故事全部标成新上榜。

首页显示上次采集时间。有失败时带上失败来源数。

## 关键词

命中标题链到该故事的第一条 http 或 https 地址。没有这种地址时，文字不可点。

「这次采集没有命中关键词。」写在数据库里，重启还在。

## 设置页

去掉配色、组件、字体和角色表。健康检查和设置页不再显示邮件 SMTP。

## 发现页匹配

兴趣匹配收紧：对得上的是写下的搜索词，或保存时存下来的别名。空泛的方向名称、以及「研究」「方向」这类过宽的别名，不再单独把故事算进这个方向。兴趣命中仍然不会把故事推上首页。

## 界面

页头可以放操作按钮。首页「立即采集」放在标题旁边。正文字体改为 IBM Plex Sans。侧栏去掉条纹，主栏放宽。角色图按同一套结构重画。减少动态效果时，首页不再保留雷达扫描。
