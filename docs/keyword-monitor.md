# 关键词监控这一版

这一版是本地运行的 AI 热点监控。它从多个来源把同一件事收成一条故事，用中文放在首页，并按用户设的关键词提醒。日报、发现和邮件还没做。

技术上是 React + Vite 前端、Express + SQLite 后端，类型放在 `shared`。开发时页面在 `localhost:5173`，`/api` 代理到 `127.0.0.1:3001`。

## 实现了什么

**来源。** 微博热搜、B 站热门、Hacker News、RSS（机器之心、量子位、OpenAI、Anthropic、Google AI、Hugging Face）、GitHub、arXiv、搜索结果页（搜狗、Google、DuckDuckGo）和 twitterapi.io。

关键词会再搜一次：搜狗或 DuckDuckGo，以及已经配置密钥的 twitterapi.io。关键词搜索不走 Google。搜索请求串行，间隔至少 90 秒，再加 0–30 秒抖动。每个搜索引擎每天最多 80 次，推文每天最多 150 条。没有 `TWITTERAPI_IO_API_KEY` 时，X 这一路记为未配置，不发请求。

**首页。** 只放近 7 天、并且有发布时间的故事。微博和 B 站不出现。搜索结果只留已知科技站点、官方博客、机器之心和量子位。单独一条 X、Hacker News 或 GitHub 帖子，要有第二个来源才显示。排序先看来源是不是多家，再看来源强弱，再看发布时间。页面先显示 15 条，其余在「更多」后面。卡片标题优先用模型写的中文事件句。

DeepSeek 把每条首页候选判成 reliable、uncertain 或 unreliable，并给一句中文理由。unreliable 不进首页。没有密钥，或模型熔断期间，首页只留已经通过规则的故事，并标「未经过模型核实」。

**关键词监控。** 监控页可以添加、暂停和删除关键词，重复词（不区分大小写）加不进去。匹配也不区分大小写：整句出现，或关键词里至少 4 个字符的英文词出现在标题、中文摘要或原文片段里。一次采集没有命中时，页面写「这次采集没有命中关键词。」同一条故事、同一个关键词只记一次。暂停后再继续，从继续的时刻重新算，之前的故事不补发。

命中后记一条站内通知。配置了 Server酱 才发微信；没配就只记站内，渠道是 skipped。发送失败记下 HTTP 状态，页面不显示密钥。不发邮件。

**DeepSeek。** 分析走 `https://api.deepseek.com` 的 `POST /chat/completions`。密钥是服务器上的 `DEEPSEEK_API_KEY`，只在后端读。主模型是 `deepseek-v4-flash`；接口若以模型错误拒绝这个 id，再请求一次 `deepseek-flash`。这次调用关闭思考，`response_format.type` 为 `json_object`，`max_tokens` 为 4096。超过 20 秒就中止。本地不设每日请求上限，`usage_daily` 里的 `deepseek` 行只计数。连续失败 3 次后，5 分钟内不再打模型。

热度只按规则算：来源数量、条目数量、热榜和时效。可信度先算规则分（域名、跨源印证、官方域名、仿冒和诈骗用语）。有模型分时，与规则分折中。仿冒、黑名单或诈骗用语把最终分封顶在 30。没有密钥时只走规则，也不改写已经由模型写好的摘要。调用失败时保留已有摘要，写出具体原因（超时、HTTP 状态等），并停掉这一轮剩下的模型调用。采集本身不中断。

**Server酱。** 普通 Turbo 密钥发到 `sctapi.ftqq.com`。`sctp` 开头的 Server酱³ 密钥发到对应的 `push.ft07.com`。标题去掉换行并截到 32 字，请求 10 秒超时。

## 怎么跑

**采集。** `POST /api/v1/collect` 马上返回 202，采集在后台继续。动态源并行拉取，每个来源有自己的超时；卡住的记为失败，其他来源照常。搜索因为有间隔，放在后面串行。这一轮结束后先打中文摘要和可信度，再做首页判断，最后匹配关键词。

**去重。** 先按规范化网址：http 升成 https，去掉常见跟踪参数。推文按 status id，B 站按 BV 号，微博热搜按热词。网址不同时，再用 SimHash，汉明距离在 3 以内视为同一件事。Embedding 这一层固定跳过，设置页写明当前只按网址和 SimHash 合并。

**7 天。** 首页和关键词搜索用同一个 7 天窗口。搜索命中没有发布时间、早于 7 天，或不在权威站点上，就不入库。关键词推文的查询窗口也是 7 天。

**关键词。** 只对「添加或恢复关键词之后新出现的故事」做提醒，故事还要没被判成不相关。命中看标题、中文摘要，以及各来源条目的标题和原文片段。

密钥示例在 `server/.env.example`，都是空占位。真正的密钥只放在服务器的 `server/.env`，不进仓库。

按官方账号、粉丝数和浏览量筛选 X，以及禁止只凭标题相似把推文并进另一条新闻，是这一里程碑验收之后的另一次提交，不算在这一版里。
